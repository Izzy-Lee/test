🔧 처음 1회 세팅 (허브 준비)
  1. Pybricks 펌웨어 설치. 컴퓨터/갤럭시탭 크롬에서 code.pybricks.com 접속 → 화면 안내대로 51515 허브에 Pybricks 설치. LEGO 앱으로 언제든 원래 펌웨어 복구 가능합니다.
  2. 수신 프로그램 올리기. Pybricks Code 편집기에 아래 코드를 붙여넣고, 구동 모터가 꽂힌 포트에 맞게 LEFT_PORT·RIGHT_PORT만 수정한 뒤 ▶(다운로드/실행). M.V.P.의 E(뒷바퀴 구동)·F(앞바퀴 조향) 모터는 허브가 켜질 때 자동으로 찾으니 코드를 고칠 필요가 없어요. 한 번 다운로드하면 허브에 저장됩니다. 
    
          
    
        
    3. 
        
  3. Pybricks Code 연결 해제. 블루투스는 한 번에 한 곳만 연결됩니다. Pybricks Code에서 허브 연결을 끊으세요.
    4. 
        
  4. 이 앱에서 연결. 아래 ‘허브 연결’ → 목록에서 Pybricks Hub 선택. 연결되면 저장된 수신 프로그램이 자동 실행됩니다.
    5. 
        
  5. 주행! 컨트롤러로 운전하세요. 앞으로 안 가고 회전만 하면 설정 → 방향 반전 토글을 바꾸면 됩니다.
