LEGO® 51515 주행 베이스 · 바퀴 구동 모터 2개로 주행
🧱 조립하고 주행 시작하기
  1. 주행 모델 조립. LEGO MINDSTORMS 앱(또는 종이 설명서)의 51515 모델 중 바퀴로 달리는 모델을 만드세요. 추천: Tricky(바퀴 주행)나 MVP(자동차). 핵심은 좌·우 바퀴를 굴리는 모터 2개입니다.
  2. 모터를 허브에 연결. 두 구동 모터를 아무 포트에나 꽂으세요. 예) 왼쪽 바퀴 → A, 오른쪽 바퀴 → E. 포트는 앱에서 언제든 바꿀 수 있습니다.
  3. 허브 켜고 연결. 허브 가운데 버튼으로 전원을 켜고(LEGO 앱 등 다른 기기와는 연결 해제), 아래 ‘허브 연결’을 누르세요.
  4. 포트 자동 감지. 연결되면 어느 포트에 모터가 꽂혔는지 자동으로 표시됩니다. ‘감지된 모터로 자동 설정’을 누르면 좌·우 포트가 채워집니다.
  5. 주행! 조이스틱을 드래그해 운전하세요. 앞으로 가야 하는데 회전만 하면 설정에서 방향 반전 토글을 바꾸면 됩니다.
아이폰 / 아이패드 사용자
iOS Safari·크롬은 Web Bluetooth를 지원하지 않습니다. App Store에서 Bluefy(무료)를 설치하고, Bluefy 안에서 이 페이지를 열어 연결하세요. PC 크롬·안드로이드 크롬에서는 기본 브라우저로 바로 됩니다.
