# 그림책 원고 — 패드끼리 이어 쓰기

A패드에서 쓰던 그림책 원고를 B패드에서 그대로 열어 보고, 이어서 고칠 수 있게 만든 앱입니다.
원고는 구글 스프레드시트 한 장에, 그림은 구글 드라이브 폴더에 저장됩니다.
따로 서버를 빌리거나 로그인을 만들 필요가 없습니다.

- `index.html` — 패드에서 여는 앱 (이 파일 하나가 전부입니다)
- `Code.gs` — 구글 스프레드시트에 붙여 넣는 저장소 코드

---

## 1. 저장소 만들기 (한 번만)

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 하나 만들고, 이름을 `그림책 원고`처럼 붙입니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 편집기에 있던 `function myFunction() {}` 를 모두 지우고, 이 폴더의 **`Code.gs` 내용을 통째로 붙여 넣습니다.**
4. 💾 저장을 누릅니다.

## 2. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 아래처럼 맞춥니다.
   - **실행 계정**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포** → 권한 승인 화면이 나오면 계정을 고르고 허용합니다.
   («이 앱은 확인되지 않았습니다» 가 뜨면 *고급 → 안전하지 않은 페이지로 이동*)
5. 마지막에 나오는 **웹 앱 URL**(`.../exec` 로 끝나는 주소)을 복사해 둡니다.

> 나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야
> 바뀐 내용이 반영됩니다. 주소는 그대로입니다.

## 3. 앱 열기

`index.html`을 웹에 올려 두고(예: GitHub Pages) 패드 사파리로 엽니다.
처음 열면 주소를 묻는 화면이 나오는데, 2번에서 복사한 `/exec` 주소를 붙여 넣으면 끝입니다.

패드 사파리에서 **공유 → 홈 화면에 추가**를 해 두면 앱처럼 전체 화면으로 열립니다.

## 쓰는 법

### A패드에서 쓰다가 B패드에서 이어 하기

1. A패드에서 **＋ 새 그림책 만들기**를 누르면 `HWBQ5J` 같은 **6자리 코드**가 나옵니다.
2. B패드에서 같은 앱을 열고 그 코드를 넣으면, 쓰던 원고가 그대로 보입니다.
3. 코드를 넣기도 번거로우면 **연결 링크 복사**로 나온 링크를 보내세요.
   그 링크를 열면 저장소 주소까지 함께 들어가서 바로 열립니다.

고친 내용은 손을 뗀 뒤 1초쯤 지나 저절로 저장되고(위쪽에 *저장됨* 표시),
다른 패드는 바뀐 게 있는지 확인해서 가져옵니다.
확인 간격은 한창 작업 중이면 5초, 손 놓고 있으면 15초 → 45초로 늘어납니다.
(Apps Script는 계정마다 하루 실행 시간이 정해져 있어서, 쉬는 동안 아끼려는 것입니다)

### 두 패드에서 동시에 고쳤을 때

한쪽 내용을 조용히 지워 버리지 않습니다.
나중에 저장한 쪽에 «○○에서 방금 원고를 고쳤어요» 안내가 뜨고,
**상대 원고 보기** / **내 원고로 덮기** 중에 고를 수 있습니다.

### 글상자

- 아래 **흰 상자 · 진한 상자 · 테두리** 중 하나를 누르면 글상자가 생깁니다.
- 글상자를 한 번 누르면 선택, 선택된 상태에서 한 번 더 누르면 **글 고치기**로 들어갑니다.
  (두 번 톡톡 눌러도 됩니다)
- 고른 뒤 아래 도구로 크기·글씨체(또박또박/손글씨)·정렬·앞뒤 순서를 바꿉니다.
- 글이 넘치면 상자가 알아서 조금 커집니다.

### 그림

- **그림 넣기**로 사진첩이나 파일에서 고릅니다.
- 크기 조절은 두 가지입니다.
  - 네 귀퉁이의 동그란 **손잡이를 끌기**
  - 그림 위에 **두 손가락을 올리고 벌리거나 오므리기**
  - 둘 다 **원래 비율을 그대로 지킵니다** (찌그러지지 않아요)
- 손가락 하나로 끌면 자리를 옮깁니다. **가운데 선을 넘겨 끌면 옆 쪽으로 넘어갑니다.**
- **그림 그리기 앱에서 그린 손그림도 흐려지지 않습니다.** 원본이 2048px 이하면 아예 손대지 않고
  그 파일 그대로 올립니다(화질 손실 0). 더 크면 2048px로 줄이되, 선 그림처럼 PNG가 작게 끝나는
  그림은 PNG 무손실로 그대로 두고, 사진처럼 PNG가 너무 커지는 것만 JPEG로 바꿉니다.
  투명 배경도 흰색으로 덮지 않고 그대로 둡니다.
- 한 번 올린 그림은 원고를 아무리 여러 번 저장해도 다시 압축하지 않습니다.
  원고에는 파일 ID만 오가기 때문에, 고칠수록 그림이 뿌예지는 일은 없습니다.

### 장면

한 장면은 펼침면(왼쪽 쪽 + 오른쪽 쪽) 두 쪽입니다.
아래 **◀ ▶** 로 넘기고, **＋ 장면 추가**로 늘립니다.
지울 때는 위쪽 **☰ → 이 장면 지우기**.

## 알아 두면 좋은 것

- **자리와 글자 크기는 화면 크기와 상관없이 똑같이 보입니다.** 모든 좌표를 쪽 크기의 비율(%)로
  저장하기 때문에, 큰 패드에서 놓은 그대로 작은 패드에서도 같은 자리에 있습니다.
- **인터넷이 끊겨도** 그 기기에 남아 있는 원고를 열어 볼 수 있고, 다시 연결되면 저장합니다.
  (다만 끊긴 동안 다른 패드가 고쳤다면 위의 안내가 뜹니다)
- **그림이 안 보일 때**: 회사·학교 계정이라 드라이브 링크 공개가 막혀 있으면
  앱이 알아서 Apps Script를 통해 그림을 내려받아 보여 줍니다. 조금 느릴 뿐 보이긴 합니다.
- **원고 백업**: 스프레드시트의 `Stories` 시트가 원본입니다. 시트를 복사해 두면 그대로 백업됩니다.
- 6자리 코드를 아는 사람은 누구나 열고 고칠 수 있습니다. 반 아이들끼리 쓰기엔 편하지만,
  바깥에 공개하면 안 되는 원고라면 코드를 함부로 흘리지 마세요.

## 저장 구조

`Stories` 시트 한 줄이 그림책 한 권입니다.

| 열 | 내용 |
|---|---|
| id | 6자리 코드 |
| title | 제목 |
| updatedAt | 마지막 저장 시각 |
| version | 저장할 때마다 1씩 오름 (동시 수정 감지에 씁니다) |
| editor | 마지막으로 고친 패드 이름 |
| data1…data8 | 원고 본문(JSON). 칸 하나에 5만 자 제한이 있어 나눠 담습니다 |

그림은 드라이브의 **`그림책 이미지`** 폴더에 들어가고, 원고에는 파일 ID만 남습니다.
